# Native Qt UI Implementation Plan

> **For agentic workers:** Use the approved design and implement the isolated ownership areas below. Steps use checkboxes for tracking.

**Goal:** Build the approved spring interview UI as runnable Qt 6.12 native pages and two floating windows.

**Architecture:** Reusable presentation modules consume properties and emit intent signals. Application pages and an in-memory demo controller live in Chunfe; Main owns window lifecycle. No network, audio, persistence, file reading or business backend.

**Tech Stack:** Qt 6.12, Qt Quick Controls Basic, C++23/CMake, existing TextBlock and application fonts.

**Spec:** `docs/superpowers/specs/2026-11-03-native-ui-design.md`

## Constraints and review focus

- Preserve Neutral styling, logo, 64px sidebar and prior work.
- Cancel/restart checks cannot launch stale sessions; pause/finish must stop progression.
- Main stays hidden for the entire interview; closing either floating window restores reachable main UI.
- Long text scrolls; streaming answer stays associated with the correct question.
- Background/settings survive route changes and sessions within one process only.
- Check compact window sizes, keyboard access, disabled controls and no QML warnings.

## Fixed integration contracts

- Theme singleton exposes light/dark palette; controls accept standard Qt Control properties. AppButton adds `variant` (primary/secondary/ghost/danger); AppIcon uses `name`, `color`, `size`; IconButton uses `iconName` and `text` as accessible label.
- TranscriptPanel: `messages` array of `{role,text,time}`, `paused`, `collapsed`, `elapsedText`, `statusText`; signals `pauseRequested()`, `collapseRequested()`, `finishRequested()`, `dragRequested()`.
- AnswerPanel: `question`, `answer`, `generating`, `pendingQuestion`, `collapsed`; signal `collapseRequested()`, `dragRequested()`.
- Pages require `property var controller`. Controller provides settings/profile/history, mutable state operations, `notify(message)`, `startChecks()`, `cancelChecks()`, `beginInterview()`, `finishInterview()`, `togglePause()` and `openRecord(id)`; exact page-facing properties defined in agent contract.
- Main owns window visibility. DemoController can emit `interviewStarted()` / `interviewFinished()` and `notification(message)`.
