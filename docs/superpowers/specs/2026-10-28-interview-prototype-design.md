# 春风 · 面试辅助交互原型

用户于 2026-10-28 在 grilling 访谈后确认本方案。

> 2026-11-03 更新：入口、背景复用与视觉方案以 `2026-11-03-prototype-simplification.md` 为准。



## 目标与交付

独立可点击的 HTML 桌面应用原型，位于 `prototypes/interview-assistant/`。沿用春风名称，先展示 macOS 场景，布局适用于三平台。原型用于验证界面与状态，不连接真实录音、ASR 或模型服务，不改动 Qt 主应用。仅 Markdown 导入、页面操作、浏览器本地文字记录与导出为真实操作。

## 已确认流程

1. 新建独立会话，可上传 `.md` 资料作为本场背景；不引入面试档案/资料库，下场不自动沿用。
2. 模型配置包含 API 地址、Key、模型名称及连接测试。原型测试为模拟；不持久化真实 Key，不发送文件或对话。
3. 启动前检查本地引擎、系统音频、麦克风、模型连接、资料状态。失败时给出明确重试及可用降级模式。
4. 悬浮球与双方字幕处于同一无边框透明窗体，整体可拖动。固定紧凑视口约能看六句短话；按时间顺序左右对齐，左为对方、右为我方；长句换行，历史滚动，回看暂停自动滚动。
5. 答案窗默认右侧停靠，可独立拖动；到屏幕边缘调整位置。默认一句核心结论、三个要点、相关经历提示，可展开完整答案/代码。
6. 自动识别问题。未固定时，新答案首段就绪后切换；固定时显示待看新题。支持手动补题、忽略误判、修正问题后重答。个人经历只引用所给资料，无依据时提示补充。
7. 收起继续运行；暂停停止接收新内容；结束保存文字并进入记录页。故障保留最后有效内容，标明暂停/未更新及问题归属，支持重试。
8. 浏览器本地自动保存文字记录（原型存储），支持重命名、删除、Markdown 导出；不录制音频。演示记录明确标示。

## 视觉与范围

浅色主界面，低饱和青绿色强调色；透明悬浮容器内的胶囊与答案卡为深色半透明实底。清楚表达状态，减少信息密度。不包含笔试截图、模拟面试、商业化/账号、真实系统权限与真实网络请求。

## 方案选择

已选择可点击 HTML 原型，便于快速验证跨页面与悬浮交互。Figma 静态稿不能完整展示状态，直接 Qt 实现会提前投入业务集成；后续可依据验证结果迁移至 Qt/QML。

## 设计者默认

- 会话按日期命名，可编辑；资料导入可选，提供明确标示的演示 Markdown。
- 文件以纯文本预览和存储，不执行 HTML/Markdown 脚本。API Key 仅保留在当前页内存。
- 演示场景设在浏览器画布内，清楚注明不会采集真实音频；右上角演示控制可推进对话和模拟故障。
- 不要求联网和安装前端依赖。桌面为主，同时保证窄窗口可操作。
