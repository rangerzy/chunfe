# 居中启动页与轻量设置（已确认）

用户否定紧凑版的全宽黑按钮、大状态列表和过多方框，确认恢复上一版居中启动构图，同时保留较小的窗口；本轮同时更新网页原型。

- Qt 主窗继续默认 820×560、最小 760×520，侧栏仍固定 64px。
- 首页内容组居中、略偏上：官方麦克风图标、标题、短说明、180×44 开始按钮、三项可点击的横排状态。取消状态列表的大外框。按钮圆角12，图标容器圆角16。
- 设置页统一最大宽度640，保留136标签列、20列间距、38高控件与说明文字对齐；移除外层大框，用间距和细分隔线分组，字段/普通按钮圆角10。背景编辑器保持整行210高。
- 保留 Neutral 黑白灰、深色清晰文案、官方 IconPark 图标、现有页面与悬浮窗交互。无新增真实功能。
- 网页原型同步首页、设置、导航视觉；清除早期已否决的补题/代码/固定回答等入口与演示说明，使展示的功能与当前 Qt 一致。保留原型已有浏览器内资料/记录操作。

验证：Qt 构建/QML lint/现有测试、默认与最小窗口渲染检查；原型脚本语法、浏览器页面/进入结束流程及对应尺寸截图检查。
