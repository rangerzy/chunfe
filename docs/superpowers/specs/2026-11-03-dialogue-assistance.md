# 实时对话辅助（已确认）

产品定位为通用实时对话辅助。用户确认问题、请求和异议均可提供回应建议，Qt页面与网页原型同时更新。本轮仍只实现页面、交互和固定mock，不接入模型或实时语义识别。

- 统一用户可见文案：开始一段对话、开始对话、暂停/继续/结束对话、对话记录、对方、背景资料、回应建议。记录按“条建议”计数，建议关联“对应对话”。提示、无障碍标签、空态和导出也使用同一术语。
- 沿用已确认的居中首页、紧凑窗口、设置布局与两个浮窗，不增加场景选择器、多人识别、总结、补题或其他功能。
- 问题、请求和异议各产生一次自动流式建议，保留对应片段和类型；新建议准备期间保留上条建议。普通陈述只进入转写，既不生成新建议，也不中断或替换已有建议。
- 固定时间线：问题“这次方案最需要先确认的是什么？”；陈述“我把刚才讨论的要点记下来了。”；请求“请把下一步的安排和各自负责的事项整理一下。”；异议“这个时间可能来不及，而且现在的范围有点大。”；陈述“我先把相关资料发到群里。”。
- 背景资料改为身份、业务资料与沟通偏好，保持一次保存、后续复用及每次对话独立快照。
- 用户已有记录、标题和背景不改写。内部历史字段/模块路径暂保留兼容，建议记录新增kind；旧记录缺省类型可回退为问题。

验证应覆盖三类回应与普通陈述的差异、暂停/结束/快照、默认和最小窗口、网页导出和无脚本错误。历史设计文档保留为决策记录，当前README同步新定位。
