# 春风原生 Qt 页面与交互

用户于 2026-11-03 确认本轮全部建议，授权开发。

- 使用 Qt 6.12 / Qt Quick，实现原型的首页、背景、模型、音频转写、记录列表与详情。沿用 Neutral 黑白灰、错位双引号 Logo、64px 固定侧栏（单项悬停展开且正文不移动）。
- 只实现页面与交互：mock 数据只存内存，重启重置。背景在本次运行内跨会话复用；表单、搜索、删除和记录浏览可操作。文件导入/导出、模型连接、引擎启动只展示模拟反馈，不读写用户文件、不联网、不采集音频。
- 开始时检查弹窗模拟进度，完成后自动隐藏主窗，显示两个真实无边框置顶窗口：透明对话条（左右胶囊、约六句话）与回答思路。两窗可拖动，不显示模拟桌面。
- 对话条提供暂停/继续、折叠、结束。折叠只改变内容可见性；结束或系统关闭任一悬浮窗统一结束本场并恢复主窗记录详情。取消检查不应延迟进入；暂停不推进 mock 文本。
- 回答窗展示问题与首次回答全文，模拟流式输出、支持滚动。移除手动补题、修改问题、重新生成、完整答案展开、代码示例、固定与队列操作。新问题准备时保留带原问题的旧答案，开始输出新答案时切换；旧内容可在记录中回顾。
- 通用 `modules/ui_controls`、`modules/interview_transcript`、`modules/answer_panel` 为独立静态 QML 模块，属性输入/信号输出；复用 `TextBlock`。页面、mock 数据、窗口生命周期放 `src/gui`，不向 `src/core` 添加业务占位。
- 保留现有字体加载与许可入口。既有 prototype、calendar、打包行为不做无关修改。
- 本机 Qt 6.12.0 编译、QML lint、已有测试和原生窗口交互检查；跨平台实测范围如实报告。
