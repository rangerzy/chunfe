# 春风原型：简化入口与 Neutral 视觉

2026-11-03 用户在 reviewing/grilling 中明确修改，覆盖 2026-10-28 方案中对应条目。

## 已确定

- 首页仅一个“开始面试”主要动作及模型、引擎、背景三项紧凑状态；会话按时间自动命名，历史从侧栏查看。
- 背景资料在“设置 → 我的背景”首次录入/导入 Markdown 后本地长期保存，后续新会话自动带入，平时无需重复编辑。
- 会话聊天上下文相互独立；每场记录保存开始时的背景快照。删除会话不删除全局背景。
- 开始时显示环境检查弹窗，通过后自动进入浮层，不再要求点击“开始面试”确认。检查期间可取消；失败时提供重试/明确选择的降级，不自动绕过失败。
- 用户明确要求 https://github.com/shadcn-ui/ui 风格，原青绿/叶子/渐变装饰移除。实现采用官方 Neutral 风格的语义色和组件尺寸，不迁移独立原型的技术栈。
- 主界面默认 Neutral 浅色、浮层 Neutral 深色是本次设计者采用的默认。透明窗体、左右字幕、约六句话、独立答案窗等既有交互继续适用。

## 实现边界

仍为独立无依赖 HTML/CSS/JavaScript 原型。API/音频/转写是模拟；资料保存、记录操作可用。模型测试/异常演示放设置中，首页不增加演示表单。没有引入账号、后台或网络传输。

## 主要验证

一次保存背景后刷新/新建多场均自动带入；取消检查不会延迟进入；正常检查自动进入；失败停留且能重试；Neutral 样式覆盖首页、资料、模型、设备、记录、弹窗和浮层；600/768/1280 宽度下内容与按钮可达。

## 已确认的菜单交互补充

侧栏在所有宽度下固定占位 64px，默认只显示图标，当前选中项也不常驻文案。仅悬停/键盘聚焦的按钮向右覆盖展开，约 200ms 滑入与淡入；图标、侧栏和正文位置不变。展开文案区域可点击，移入时保持展开，移出/失焦收回。减少动画偏好下取消过渡。品牌保留图标，分组标题和底部说明隐藏，分隔线保留。

菜单验证：浏览器实测默认/展开后侧栏宽度均 64px，正文左边界均 64px；仅当前项文案可见，展开文案属于同一链接且可点击。键盘 focus-visible 可展开，鼠标指向其它项时优先显示该项。600px 宽度无横向溢出，已恢复浏览器默认尺寸。
