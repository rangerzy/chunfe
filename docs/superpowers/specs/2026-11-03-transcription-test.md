# 转写测试入口（已确认）

用户确认在转写引擎配置增加“测试转写”，Qt与网页原型同步。仍为页面、交互与mock，不新增真实采集、转写或模型调用。

- 入口位于“音频与转写”的转写引擎行，打开紧凑居中弹窗，不拉长设置页面。主窗尺寸与现有布局保持。
- 上方两路信息分别为SPK（系统声音）与MIC（麦克风），沿用设置中选择的设备，展示设备名与动态音量条。按用户最新反馈，不显示“等待声音”“有声音”等通道状态文字；用户直接通过音量条判断。内部状态保留用于异常图标颜色与无障碍描述。
- 下方按时间显示转写文本，每条带SPK/MIC来源标签及时间，逐步更新文本，支持滚动查看历史。
- 打开自动开始；引擎未就绪时先展示启动状态。停止保留文本供查看，重新测试清空本次结果并从头开始；关闭/离开页面/正式对话开始均停止测试、释放测试定时器。迟到的引擎启动完成不会复活已停止或关闭的测试。全局引擎可保持就绪，不因关闭测试被停止。
- 测试状态独立，不生成回应建议、不写入对话或localStorage记录、不改变背景资料。异常状态使用内部测试数据覆盖，不增加用户可见的演示控制。
- 视觉沿用Neutral、圆角与官方IconPark，无额外功能说明。Qt展示拆为modules/transcription_test的纯展示模块，mock和应用生命周期由src/gui管理。

固定转写样例交替SPK/MIC：“我们先确认一下今天讨论的内容。”“好的，我这边可以清楚地听到。”“接下来一起核对时间和安排。”“我会把确认的事项整理下来。”列表限制最多40条，避免长时间运行无限增长。

验收：默认/最小窗口内弹窗完整、双通道状态与来源正确、静音与异常区分、停止/重测/关闭/启动竞态、测试与正式对话/记录隔离；Qt构建lint测试及网页完整交互与截图检查。
