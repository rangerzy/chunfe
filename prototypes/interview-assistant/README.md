# 春风 · 对话辅助交互原型

与 Qt 6.12 页面保持一致的独立前端原型，用于查看布局和交互，不接入音频、转写或模型服务。

## 打开

直接打开 `index.html`，或从项目根目录执行：

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory prototypes/interview-assistant
```

然后访问 http://127.0.0.1:4173 。不需要安装前端依赖或联网。

## 当前设计

- 首页采用居中的启动组：图标、标题、180 × 44 开始按钮，以及模型、转写、背景三个可点击状态入口。
- 模型和音频设置采用 136px 标签列、20px 列间距、38px 高控件；说明文字与控件对齐。背景为整行编辑区。设置页通过间距和细分隔线分组，不包裹大卡片。
- “音频与转写 → 测试转写”打开独立弹窗，分别展示 SPK 系统声音、MIC 麦克风的设备与动态电平，不显示通道状态文案；设备异常通过图标颜色和无障碍描述体现。下方按来源与时间显示转写，空态为“暂无转写文本”。打开即开始，支持停止、重新测试和关闭，保留整体引擎状态。
- 主导航固定 64px，激活项黑底白图标。鼠标悬停或键盘聚焦只展开当前项文案，不推动正文。
- 页面在 820 × 560 和 760 × 520 视口中保持紧凑。更窄浏览器中表单自动改为单列，长记录可滚动。
- 进入对话后隐藏主界面，只保留对话条和回应建议。双方字幕左右分布，回应建议自动逐步显示首次全文；支持拖动、收起、暂停和结束。
- 对方提出问题、请求或异议时提供回应建议；普通陈述只进入转写，不替换或中断现有建议。等待新建议期间保留上一条内容。
- 不提供手动补题、修正、重生成、代码示例、固定答案或演示控制入口。界面只展示功能性文案，能力边界集中记录于本文。

## 体验路径

1. “背景资料”填写资料或导入 `.md`，保存一次后在后续对话复用。
2. “模型连接”设置接口信息；“音频与转写”切换设备并查看引擎状态，可点击“测试转写”检查 SPK/MIC 和转写文本。
3. 首页点击“开始对话”，检查完成后自动进入悬浮场景，无需再次确认；检查失败保留取消和重试。
4. 结束或关闭任一浮窗后，查看本次文字记录、首次回应建议和背景快照；可搜索、重命名、删除/撤销和导出 Markdown。

## 原型边界

- Markdown 纯文本读取（最多 256 KB）、页面交互、浏览器 localStorage 存储和 Markdown 导出可以实际操作。Qt 版本的资料与记录仍仅保存在当前进程内存中，两者不共享数据。
- 浏览器中的浮窗只存在于网页画布，音频、离线引擎、连接测试、转写和回应建议均为固定 mock。不会请求录音权限，不会发送模型 API 请求，也不会使用个人资料生成真实建议。
- 转写测试使用独立的固定音量与文本时间线，不读取真实音频。测试文本最多保留40条，停止时保留可查看，重新测试或关闭会清空；不进入对话记录、不触发回应建议、不写入 localStorage。引擎未启动时先自动启动，关闭测试不停止全局引擎。关闭、导航或开始正式对话都会取消测试；迟到的启动结果不会恢复已停止测试。
- API 地址和模型名可保存在当前浏览器。Key 仅保留于当前页面内存，不写入 localStorage。
- 触发类型来自固定样例的显式标注（question / request / objection / statement），没有接入语义识别。现有浏览器中保存的标题、背景与历史记录原样保留；旧记录没有类型时按“问题”显示。
- Markdown 只作为文本显示，不执行其中 HTML。默认记录及自动对话为虚构内容。
- 背景、文字记录在刷新后保留，每次对话保存独立背景快照。浏览器存储存在容量限制，需要长期保留时可导出。

## 文件与图标

- `index.html`：应用框架与资源入口。
- `styles.css` / `app.js`：首页、资料、模型、音频、检查与记录。
- `transcription-test.css` / `transcription-test.js`：独立的双通道测试视图和mock状态控制器；`app.js` 管理引擎与弹窗生命周期。
- `overlay.css` / `overlay.js`：浏览器内的对话条和首次回应建议窗口。
- `assets/iconpark.js`：与 Qt 共用的官方 IconPark SVG，来自 `modules/ui_controls/icons` 的 `@icon-park/svg@1.4.2`，不修改几何路径，仅把前景色替换为 `currentColor`。
- `assets/iconpark/LICENSE`、`NOTICE`、`SOURCE.json`：许可证与来源清单。执行 `python3 prototypes/interview-assistant/assets/iconpark/generate.py` 可从仓库原始 SVG 重新生成网页资源。

视觉采用 shadcn/ui Neutral。已确认的“错位双引号” Logo 用于侧栏与浮窗，`logo-preview.html` 保留最初的品牌对照稿。

转写测试模块公开 `window.ChunfeTranscriptionTest.createController(options)` 与 `mount(options)`，提供 `open/stop/restart/close/destroy/snapshot/advanceTick`。设备可用性、定时器及引擎状态/启动回调可由调用方注入，便于在隔离环境验证异常和取消；这些接口不构成产品内的演示控件。
